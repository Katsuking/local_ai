# クリップボード連携 音声合成 (TTS) システム

Hugging Face 等のモデルを Python で利用し、GPU を活用して高品質な日本語音声合成を行います。
環境を汚さないために専用の仮想環境 (`venv`) を構築し、メモリ上で音声を生成・再生してから特定のフォルダに WAV ファイルとして保存します。

---

## 1. 事前準備 (OS側の要件)

他の Ubuntu 環境でこのプロジェクトを再現する場合、事前に以下の条件とパッケージのインストールが必要です。

### 1-1. GPU (CUDA) 環境の確認

NVIDIA 製 GPU が搭載されており、NVIDIA 公式ドライバーがインストールされている必要があります。
以下のコマンドを実行して、GPU の情報が表示されることを確認してください。

```bash
nvidia-smi
```

### 1-2. システムパッケージのインストール

音声合成の音素解析に使う `espeak-ng` と、クリップボードのテキスト取得に使うツールをインストールします。

ご利用のデスクトップ環境（X11 または Wayland）に合わせてインストールしてください。（通常、Ubuntu の GNOME 環境では X11 用の `xclip` または両対応のツールを使用します。迷った場合は両方インストールして問題ありません）

```bash
# パッケージリストの更新
sudo apt update

# X11環境の場合 (標準的なデスクトップ環境)
sudo apt install -y espeak-ng xclip

# Wayland環境の場合 (最新のデスクトップ環境)
sudo apt install -y espeak-ng wl-clipboard
```

---

## 2. セットアップ手順

事前準備が完了したら、プロジェクトのルートディレクトリで以下のセットアップスクリプトを実行します。

```bash
# 実行権限の付与 (必要な場合)
chmod +x setup.sh

# セットアップスクリプトの実行
./setup.sh
```

### スクリプトが自動で行うこと：

1. `espeak-ng` がシステムにインストールされているか確認
2. プロジェクトディレクトリ内に Python 仮想環境 (`venv`) を作成
3. `venv` 内の `pip` のアップデート
4. GPU (CUDA 12.1対応) 向けの PyTorch のインストール
5. `requirements.txt` から依存パッケージ (`kokoro`, `sounddevice`, `pyperclip` 等) のインストール
6. 日本語形態素解析用の UniDic 辞書データのダウンロード (仮想環境内に保存されます)

---

## 3. 設定のカスタマイズ

[config.yaml](config.yaml) をテキストエディタで編集することで、設定や使用モデルを簡単に切り替えることができます。

```yaml
active_model: 'style_bert_vits2' # 使用するモデル ('kokoro' または 'style_bert_vits2')
output_dir: '/home/mojo/Music/TTS_Output' # 生成した音声ファイルの保存先フォルダ
auto_play: true # 合成後に自動再生するかどうか (true/false)

models:
  kokoro:
    repo_id: 'hexgrad/Kokoro-82M'
    # 日本語話者 (以下から選択可能)
    # 女性: jf_alpha (デフォルト), jf_gloria, jf_hiroshiba, jf_tebukuro
    # 男性: jm_koutarou
    voice: 'jf_alpha'
    speed: 1.0 # 話す速度 (0.5 〜 2.0)

  style_bert_vits2:
    url: 'http://localhost:5000/voice' # APIサーバーのURL
    speaker_id: 0 # 話者ID (0: つくよみちゃん)
    speed: 1.0 # 話す速度 (0.5 〜 2.0)
```

## 4. 実行方法

### 4-1. コマンドラインからの直接実行 (テスト用)

任意のテキストを指定して音声合成をテストできます。

```bash
./run_tts.sh --text "これは音声合成のテストです。"
```

### 4-2. テキストファイルからの読み込み実行 (長文用)

長文のテキストファイルを指定して読み込み、音声合成を実行できます。

```bash
./run_tts.sh --file /path/to/your_file.txt
# または短縮形
./run_tts.sh -f /path/to/your_file.txt
```

### 4-3. クリップボード連携実行

引数を指定せずに実行すると、現在クリップボードにコピーされているテキストを自動的に音声合成します。

```bash
./run_tts.sh
```

## 5. OSのグローバルショートカットキーへの登録

いつでもワンキーでクリップボードのテキストを音声化できるように、Ubuntu (GNOME) のショートカットキーに登録します。

1. Ubuntu の **「設定 (Settings)」** を開きます。
2. 左メニューから **「キーボード (Keyboard)」** を選択します。
3. **「キーボードショートカット (Keyboard Shortcuts)」** (または「ショートカットを表示とカスタマイマイズ」) をクリックします。
4. 一番下までスクロールし、**「カスタムショートカット (Custom Shortcuts)」** を選択します。
5. **「＋」** ボタンを押し、以下を入力して登録します：
   - **名前**: `クリップボード音声合成`
   - **コマンド**: `/home/mojo/deb/local_ai/speech_synthesis_hugging_face/run_tts.sh` (※必ず絶対パスで指定してください)
   - **ショートカット**: 任意のキー組み合わせを設定（例: `Ctrl + Super + S` や `Ctrl + Alt + S`）
6. **「追加」** をクリックして保存します。

これで、テキストを選択してコピー (Ctrl+C) し、設定したショートカットキーを押すだけで、いつでも裏で音声合成が走り、スピーカーから再生・ファイル保存されます。

## 6. 高品質モデル (StyleBertVITS2) の利用手順

より自然で人間らしい日本語読み上げを行うため、別プロセスでローカルAPIサーバーを立ち上げて StyleBertVITS2 を連携させることができます。

### 6-1. サーバーの起動 (初回セットアップ含む)

APIサーバーは完全に隔離された別のディレクトリに格納されており、以下の起動スクリプトを実行するだけで、依存ライブラリのチェック・デフォルトモデルのダウンロード・バックグラウンド起動がすべて自動的に行われます。

```bash
# クライアント側ディレクトリから起動する場合
../style_bert_vits2_server/start_server.sh
```

- 初回実行時は、各種モデル（つくよみちゃん、JVNV、小春音アミ）の取得が行われるため、しばらく時間がかかります。
- サーバーはバックグラウンドプロセスとして起動し、リッスン完了（ポート 5000）をデスクトップ通知でお知らせします。

### 6-2. サーバーの停止

音声合成を使用し終わったら、以下のスクリプトを実行してサーバーを終了させ、GPUメモリ (VRAM) を解放できます。

```bash
# クライアント側ディレクトリから停止する場合
../style_bert_vits2_server/stop_server.sh
```

- 停止が完了すると、プロセスIDが終了した旨がコンソールに表示され、デスクトップ通知でもメモリ解放をお知らせします。


### 6-3. 独自の音声モデル（クレジット不要）の作成方法

Style-Bert-VITS2 に標準付属している「学習用管理画面 (WebUI)」を使用することで、自分の声や特定の音声素材を学習させた**オリジナルの音声モデル（追加学習モデル）**をブラウザ操作のみで簡単に作成できます。自作のモデルであるため、**クレジット表記不要（完全フリー）**で使い放題になります。

#### 1. 録音データの準備
* 自分の声を録音した wav ファイル（モノラル、44.1kHz以上推奨）を複数用意します。
* 綺麗に録音した音声（合計10分〜30分程度、50〜100文程度）を、1ファイルあたり2秒〜10秒程度に切り分けておきます。

#### 2. 学習用 WebUI の起動
サーバー側の仮想環境を有効化して、付属の `train_webui.py` を実行します。

```bash
cd ../style_bert_vits2_server/style-bert-vits2
source venv/bin/activate
python3 train_webui.py
```
起動後にターミナルに表示される URL（`http://127.0.0.1:7860` など）をブラウザで開きます。

#### 3. ブラウザ（WebUI）上での操作
1. **データセット作成**: 音声フォルダを指定します（台本テキストがない場合は、AIによる自動書き起こしが実行できます）。
2. **自動前処理 (Preprocess)**: 音素変換や BERT 特徴量の抽出をワンクリックで実行します。
3. **学習 (Train)**: 学習開始ボタンを押すと、GPU（RTX 3060）を利用した追加学習が始まります。完了すると `model_assets/` ディレクトリ配下に自動的にモデルが生成されます。

#### 4. クライアント設定の変更
学習したモデルを使用する際は、既存のコードはそのままで、クライアント側の `config.yaml` の `speaker_id` などの設定を新しいモデルの指定に切り替えるだけで適用できます。
